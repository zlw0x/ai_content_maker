# Сделано AI · Правила разработки v1.1

- Работайте в существующем `ai_content_maker`. Сначала сверьте текущий код с `docs/product/PRD_TECH_SPEC_v1_1.md`, планом запуска и backlog. Учитывайте уже реализованные маршруты и данные.
- Основной агент — Coordinator. Делегируйте независимые задачи максимум трём профильным подагентам одновременно, с зафиксированными ID задач, контрактом и перечнем файлов. Подагенты работают без вложенного делегирования. Общие точки меняет назначенный владелец.
- Публичные цены и решения о доступности принимает сервер. У заказа есть версия рецепта, снимок цены и ключ идемпотентности. Trial учитывается отдельно от денег. Приватные данные выдаются только владельцу.
- Для разработки используйте mock, отключённые платежи и отдельную тестовую базу. Реальная генерация, использование средств, боевые платежи и публикация требуют отдельного решения владельца. При неизвестном исходе платной отправки используйте сверку. Храните ключи в серверном окружении, удаляйте их из диагностических данных.
- Перед сдачей укажите затронутые файлы, сценарии и результаты тестов, состояние миграций и критерии готовности. Поведение существующих маршрутов сохраняйте. Процесс и границы ролей описаны в `docs/product/SUBAGENT_WORKFLOW_v1_1.md`.
