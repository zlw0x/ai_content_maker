# Roadmap / milestones

Не начинать следующий milestone до выполнения проверяемых критериев текущего. Параллельно можно изучать внешние юридические/финансовые зависимости, но не запускать оплату без Go/No-Go.

## M0 — Repo foundation + UX sketch (этот коммит)

- [x] README, продукт, архитектура, черновые контракты, экономика, безопасность.
- [x] Каталог 10 концептуальных Apps с поиском, фильтрами и страницами.
- [x] Явный Demo Mode: нет регистрации, реальных оплат/списаний и генераций.
- [x] База инфраструктуры: compose PostgreSQL и SQL draft.
- [ ] Проверить npm install / npm run build в CI или локальной машине.

**Acceptance:** из `main` пользователь может запустить сайт и перейти из каталога на страницы приложений; кнопка генерации не создаёт платную задачу.

## M1 — Provider validation (отдельный этап)

- [ ] Уточнить коммерческие условия WaveSpeed и платежи.
- [ ] Назначить model id и validated schemas для 4 P0-сценариев.
- [ ] Минимальный server-only Wavespeed adapter, quote API, лимит стоимости на запрос.
- [ ] Тестировать только на разрешённом бюджете.
- [ ] Submission unknown/reconciliation design review.
- [ ] Показать реальные примеры 4 сценариев из лицензированных/собственных материалов.

**Acceptance:** получены 4 результата через API без утечки секретов и с фактическим учётом USD costs; повтор POST в условиях неизвестного исхода исключён.

## M2 — Account + wallet simulator

- [ ] Auth, DB migration runner, jobs DB, wallet ledger.
- [ ] Test balance, атомарный reserve/capture/release, idempotency tests.
- [ ] Background worker, provider job status, media retention policy.
- [ ] Admin basic cost/reporting, quota.

**Acceptance:** тестовая генерация с искусственными балансами проходит end-to-end, конкурентные заказы не создают отрицательный баланс.

## M3 — СБП и финансовая готовность

- [ ] Юридические и договорные предпосылки закрыты.
- [ ] ЮKassa sandbox / SBP where available, проверка webhook через GET и идемпотентное начисление.
- [ ] Фискализация и процедуры возвратов/поддержки.
- [ ] Проверка правовой и фактической обработки пользовательских файлов.

**Acceptance:** тестовые платежи и возвраты воспроизводимы; сверка сходится, реальные деньги не теряются и не удваиваются.

## M4 — Закрытая бета и последующий релиз

- [ ] Небольшая группа пользователей, метрики успешности и повторного спроса.
- [ ] Положительная contribution margin на выполненный заказ.
- [ ] Расширение до 10 Apps только после подтверждения спроса/цен.
- [ ] Публичный запуск после проверки security/compliance и мониторинга.
