# ADR-001: модульный монолит и управляемая область MVP

Status: accepted for M0
Date: 2026-11-06

## Context

Проект только начинается: нет пользователей, данных о спросе, оплаченных генераций и измеренной нагрузки. Требуются каталог, интеграция одного AI-провайдера, рублевые платежи и безопасный учёт заказов.

## Decision

- Next.js App Router для веб-интерфейса и backend-for-frontend.
- PostgreSQL как источник правды для заказов и баланса.
- Один отдельный worker для фоновых задач с lease в PostgreSQL.
- S3-совместимое хранилище для медиа с приватным доступом.
- WaveSpeed provider adapter как единственный интегрируемый провайдер до M3.
- В M0 только демонстрационный каталог, никаких публичных endpoints для оплачиваемой генерации.

## Alternatives rejected for now

- FastAPI + отдельный фронтенд: хорош при сложной Python-инфраструктуре, пока создаёт дополнительную операционную поверхность.
- Redis + очереди + отдельный брокер: не требуется на нескольких десятках/сотнях заказов в день; добавим по измерениям.
- Микросервисы и Kubernetes: избыточны по стоимости и сложности.
- Своя GPU-инфраструктура: противоречит цели low-capex агрегатора.
- Агентный менеджер model routing: преждевременный риск потерь денег.

## Consequences

Быстрый первый релиз, минимум операционных компонентов. За счёт модульных границ позже можно вынести worker, pricing и другие сервисы без перестройки доменных сущностей.
